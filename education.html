The Live Test & Marks app is a small, separate service (FastAPI + a real database) — it can't run as plain HTML/JS like the rest of this site's tools, because a real teacher login and tamper-proof scores require a server that enforces the rules, not just browser code that anyone can bypass with dev tools.

Deploy it once (see the app's own README for step-by-step Ubuntu/Nginx/HTTPS instructions), then open education.html in this project and set EDUCATION_APP_URL near the top of its script to your deployed URL, e.g. https://app.allinoneplace.online.

How it works

  1. Teacher signs up, creates a class, adds students, builds a test, and publishes it.
  2. Teacher shares each student's personal test link (or their username/password, if you'd rather they log in) — one link per student, copied straight from the live sheet.
  3. Student opens the link — no login, no account needed — and takes the test. It's graded automatically the instant they submit.
  4. Student sees a plain "Test submitted" finish page. The same link can't be opened again to retake it or see the quiz — it will only ever show that finish page from then on.
  5. Teacher watches the live marks sheet update in real time as each student finishes — no refresh needed.

Why this needs real login (not just a code)

An earlier version of this page tried to do all of this with only JavaScript in your browser. That can look like it works, but it can never actually be secure — anyone can open their browser's dev tools and read or edit anything running there. Real security has to live on a server you control:

Real teacher loginPasswords are hashed (bcrypt) and never stored in plain text; sessions use a signed token nobody can forge.
Ownership-checked everythingA teacher can only ever see, publish, or delete their own classes and tests — enforced on every request, server-side.
Owner-only deleteDeleting a test removes it and every recorded score from the database — and only the teacher who created it can do it.
A real, shared databaseScores are recorded once, centrally — not scattered across each visitor's own browser storage, and not editable by students.
