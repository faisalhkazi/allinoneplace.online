FORMAT COVERAGE

What is preserved?

DOCX

Headings, paragraphs, bold/italic/underline, text colors, sizes, alignment, spacing, shading and basic tables are reconstructed in browser preview. Full-fidelity PDF uses the local Office rendering engine.

XLSX

Sheets can be extracted to CSV/HTML. Full-fidelity PDF uses LibreOffice so print areas, cell styling and spreadsheet layout are retained much better.

PPTX

Slide text can be extracted locally. Full-fidelity PDF uses LibreOffice to retain slide layout, theme styling and positioning.

Online file conversion

The file converter is designed for common document workflows such as converting supported Word, spreadsheet and presentation files to PDF. The browser sends the selected file to the conversion service, where the appropriate office-conversion engine processes it and returns the result.

For privacy and safety, avoid uploading confidential documents, passwords, financial records or sensitive personal information unless you understand and accept the service's processing environment.

Supported workflow

Choose a supported file, select the requested output when available, start the conversion and download the returned file. If a conversion fails, try a simpler document or verify that the source file opens normally in its original application.

Frequently asked questions

Does conversion happen entirely in the browser? No. Supported Office-to-PDF conversions use a server-side conversion service.

Can every file be converted? No. Support depends on the formats and conversion engine available on the backend.
